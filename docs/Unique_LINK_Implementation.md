# Implementation: Unique LINK Labels & Collision Avoidance

## Summary

Implemented globally unique LINK labels to prevent collisions when using the same label names (A, B, C...) across multiple trees in the Grammatomy project.

## Changes Made

### 1. **Core Mutation Engine** ([mutation.py](../src/core/grammatomy/mutation.py))

#### Added `uuid` import
```python
import uuid
```

#### Updated `reabsorb()` method
- **Old**: Expected exact `LINK-A` matching
- **New**: Accepts both `LINK-A` (legacy) and `LINK-A-<uid>` (new)
- **Matching logic**: Searches for exact match or prefix match on `LINK-{label}-`
- **Safety**: Raises error if multiple candidates found (prevents silent corruption)

#### Updated `detach()` method
- **New**: Generates unique 8-character UID via `uuid.uuid4().hex[:8]`
- **Format**: Both forward and back links now use `LINK-{label}-{uid}`
- **Example**: `LINK-B-52f8aab3`, `LINK-0-7ee98ebb`

### 2. **Fragmentation Engine** ([fragmentation.py](../src/core/grammatomy/fragmentation.py))

#### Added `uuid` import
```python
import uuid
```

#### Updated `fragment()` method
- Generates unique 8-character UID for each extracted subtree
- All LINK nodes in fragment now use format `LINK-{label}-{uid}`
- Updates internal PTB representations accordingly

#### Updated `defragment()` method
- Matching logic now accepts both old and new formats
- Uses same flexible matching strategy as mutation engine

### 3. **API Layer** ([mutation.py router](../src/api/app/routers/mutation.py))
- **No changes required**: Router passes `link_label` (base label) unchanged
- Fully backward compatible with both old and new LINK formats

### 4. **Frontend** ([grammatomy-app.ts](../src/web/src/grammatomy-app.ts))
- **No changes required**: Already sends only base label to `/api/mutation/reabsorb`
- Fully compatible with new unique link format

### 5. **Documentation**
- Added [LINK_Labels_and_Collisions.md](../docs/LINK_Labels_and_Collisions.md) with format details and usage guide

## Format Specification

### New Format (Generated by Detach/Fragment)
```
LINK-<base_label>-<uid>
```
- **base_label**: A-Z or Z0, Z1, ... (matches old naming convention)
- **uid**: 8 hex chars from `uuid.uuid4().hex[:8]`
- **Example**: `LINK-R-d74b945d`, `LINK-B-52f8aab3`

### Legacy Format (Still Supported)
```
LINK-<base_label>
```
- **Example**: `LINK-A`, `LINK-R`
- Continues to work with new matching logic

## Key Features

✓ **Globally Unique**: UIDs prevent collisions across all trees in a project  
✓ **Backward Compatible**: Old LINK format still recognized and works  
✓ **Transparent to Frontend**: No UI changes needed; sends base label only  
✓ **Safe Matching**: Multiple matches raise error instead of silently corrupting  
✓ **Nested Safe**: Handles complex reabsorption chains without collision risk
